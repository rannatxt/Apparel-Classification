01 — Motivation

Why Is This Hard?

Classifying apparel by cultural origin is a genuinely difficult computer vision problem, not just a label-assignment exercise.

🥻 Visual Overlap

An Indian Anarkali dress and a Western A-line evening gown share virtually identical silhouettes. Shape-based features alone cannot separate them — the classifier must learn motifs, fabric drape, and garment construction.

🌐 Fusion Garments

The Indo-Western class exists precisely because garments like the Nehru jacket and dhoti pants deliberately blend both design languages. These are authentic fusion categories, not random mixtures of the other two classes.

🤝 Ethical Classification

All classification is based on garment visual characteristics only — silhouette, drape, motifs, layering, and construction. The model must never infer the race, ethnicity, gender identity, religion, or age of the wearer.

📦 Inclusive E-Commerce

Existing fashion classifiers are predominantly trained on Western clothing datasets. This project directly addresses that gap by building a balanced, openly reproducible pipeline that treats Indian and Indo-Western apparel as first-class categories.

02 — Dataset

Dataset Preparation

Built from two public Kaggle datasets using a reproducible, seed-controlled pipeline. Every category assignment is documented; ambiguous categories are excluded, not guessed.

🔍 Category Mapping (not guessed)

Each source category is explicitly mapped to Indian / Western / Indo-Western with a documented reason. Ambiguous categories (palazzo, gown, dupatta, blouse, petticoats, footwear) are excluded with written justification in ambiguous_excluded.csv.

🛡️ Leakage Prevention

Duplicate detection runs before splitting. Exact duplicates (MD5) and near-duplicates (pHash, Hamming distance ≤ 6) are removed from the candidate pool so the same image cannot appear in both training and test sets.

04 — Models

Model Comparison

Three architectures are evaluated under identical conditions on the same dataset split. Results will be updated here once training is complete.

📱 MobileNetV3

Lightweight depthwise separable convolutions. Efficient for mobile/edge deployment. Expected to be fastest at inference.

🏗️ ResNet50

Residual connections enabling deep 50-layer training. Established baseline for image classification. Strong feature extraction for texture and shape.

👁️ Vision Transformer (ViT)

Patch-based self-attention mechanism. Strong at capturing global garment structure and long-range visual patterns like motifs and drape.

05 — Edge Cases

Edge-Case Profiling

614 images were automatically flagged for edge-case review based on garment characteristics. These are candidates for manual spot-check — labels are not automatically changed.

Visually Similar
373
Images where Indian and Western garments share a similar silhouette (e.g. Anarkali vs A-line gown). Highest classification risk.
Hybrid / Fusion
200
All Indo-Western images. Authentic fusion garments (dhoti pants, Nehru jacket) that blend both design languages by construction.
Ambiguous
41
Images where the garment label could not be confidently assigned from category name alone. Flagged for manual review.

Edge-Case Candidate List

All flagged images are recorded in dataset/metadata/edge_case_candidates.csv with their edge_case tag, source category, and image path. The file contains 614 rows ready for manual spot-check. No labels were automatically changed based on edge-case flags.

06 — Limitations & Ethics

Known Limitations & Ethical Notes

Classification by garment only. This system classifies garments, not people. No demographic information (race, ethnicity, gender identity, religion, age) is used as a feature or inferred as output. Garment labels are assigned based on silhouette, drape, fabric structure, motifs, and construction — never based on the appearance of the wearer.

⚠️
Small Indo-Western class: Only 200 images (6.3% of total). The model may underperform on this class. Use balanced accuracy and per-class F1 for fair evaluation.
🔑
Caption-derived Western labels: DeepFashion Western categories were derived by keyword-matching on image captions, not discrete folder labels. Mismatches are possible.
🧠
Indo-Western is not a random mix: dhoti pants and Nehru jackets are authentic fusion garments. Creating Indo-Western by mixing Indian and Western images would be methodologically incorrect.
📏
Ambiguous categories excluded: palazzo, gown, dupatta, blouse, petticoats, and footwear were excluded rather than arbitrarily assigned. See ambiguous_excluded.csv.
🖼️
Dataset licences: IndoFashion and DeepFashion-MultiModal are research datasets. Check their respective Kaggle pages for licence terms before commercial use.
07 — Reproduce

Reproduce This Dataset

Every step is scripted and seed-controlled. Run the pipeline on any machine with Python 3.10+ and a Kaggle account.

1. Install Dependencies

pip install kaggle Pillow imagehash matplotlib

2. Set Up Kaggle Credentials

# Go to https://www.kaggle.com/settings → API → Create New Token
# Save the downloaded token to:
# Windows: C:\Users\<you>\.kaggle\access_token
# Linux  : ~/.kaggle/access_token

3. Run the Pipeline

py -3 prepare_dataset.py
# Or skip the download if already done:
py -3 prepare_dataset.py --skip-download

4. Validate

py -3 validate_dataset.py
# Expected output: OVERALL: PASS (16/16)

5. Use in PyTorch

from torchvision import datasets, transforms
from torch.utils.data import DataLoader

transform = transforms.Compose([
    transforms.Resize((224, 224)),
    transforms.ToTensor(),
    transforms.Normalize(
        mean=[0.485, 0.456, 0.406],
        std =[0.229, 0.224, 0.225]
    ),
])

# Classes auto-detected: Indian, Indo-Western, Western
train_ds = datasets.ImageFolder(
    "dataset/train", transform=transform
)
val_ds = datasets.ImageFolder(
    "dataset/val", transform=transform
)
test_ds = datasets.ImageFolder(
    "dataset/test", transform=transform
)

train_loader = DataLoader(train_ds, batch_size=32,
                          shuffle=True, num_workers=4)
val_loader   = DataLoader(val_ds,   batch_size=32,
                          shuffle=False)
test_loader  = DataLoader(test_ds,  batch_size=32,
                          shuffle=False)
